# Yogani Peh — Property Website

A self-contained static HTML website with inline CSS, JavaScript, and embedded images.

## Deploy to Vercel

Import this GitHub repository into Vercel. Use Framework Preset: Other, leave the Build Command empty, and serve the repository root. No dependency installation or environment variables are required.

## Content

- Chinese / English language toggle with a remembered preference.
- Six initial property cards and three more revealed by View More.
- WhatsApp enquiry drafts; no form data is stored by the website.
- Embedded profile and listing photos.

The nine property listings are imported snapshots, not an automatic EdgeProp feed. Some sizes and room counts remain unverified. Testimonials remain clearly labelled placeholders. Confirm prices and availability before relying on listing information.
